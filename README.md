A simple and efficient Fish Shop Management System built with the MERN stack (MongoDB, Express.js, React.js, Node.js). This system helps manage daily operations like customer records, inventory tracking, supplier details, and fishing boat trips.

🔧 Features
Manage customers, suppliers, inventory, and boat trips

Add, update, and delete records easily

Organized interface for smooth workflow

🛠️ Tech Stack
Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

# Clone the repo
git clone https://github.com/yourusername/fish-shop-management.git

# Install and run backend
cd backend
npm install
npm start

# Install and run frontend
cd ../frontend
npm install
npm start
